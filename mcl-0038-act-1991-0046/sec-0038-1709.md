# MCL 38.1709 Determination by retirement system whether domestic relations order is EDRO; procedure; notice.
Sec. 9. Each retirement system shall establish a reasonable procedure to determine if a domestic relations order is an EDRO under this act. The retirement system shall promptly notify the participant and alternate payee named in a domestic relations order that the retirement system has received the domestic relations order. The notice shall include a description of the procedure by which the retirement system determines if the domestic relations order is an EDRO under this act.
History: 1991, Act 46, Imd. Eff. June 27, 1991
