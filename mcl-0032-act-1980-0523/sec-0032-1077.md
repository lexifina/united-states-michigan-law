# MCL 32.1077 Person subject to code as principal.
Sec. 77. A person subject to this code is a principal if the person commits 1 of the following acts:
(a) An offense punishable by this code or aids, abets, counsels, commands, or procures the commission of the offense.
(b) Causes an act to be done which if directly performed by the person would be punishable by the code.
History: 1980, Act 523, Eff. Mar. 31, 1981
