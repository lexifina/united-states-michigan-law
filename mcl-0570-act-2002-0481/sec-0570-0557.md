# MCL 570.557 Sale of special tool at public auction; conditions.
Sec. 17. If the end user has not been paid the amount due within 90 days after the notice has been received by the customer provided in section 15, the end user may sell the special tool at a public auction if both of the following occur:
(a) The special tool is still in the end user's possession.
(b) The end user complies with section 19.
History: 2002, Act 481, Imd. Eff. June 27, 2002
