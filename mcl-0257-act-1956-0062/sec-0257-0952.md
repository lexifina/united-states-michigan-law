# MCL 257.952 Identification and publication of code adopted by reference; notice.
Sec. 2. The code or ordinance passed shall clearly identify the code adopted by reference. The code need not be published in full. Publication of the code or ordinance shall be supplemented by a notice of the purpose of the code and the fact that a complete copy of the code is available for inspection by the public at the office of the city, township, or village clerk.
History: 1956, Act 62, Eff. Aug. 11, 1956; Am. 1979, Act 119, Imd. Eff. Oct. 17, 1979
