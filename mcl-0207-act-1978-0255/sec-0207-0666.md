# MCL 207.666 Report on status of exemption.
Sec. 16. Each governmental unit granting a commercial redevelopment exemption not later than October 15 each year shall report to the commission on the status of each exemption, including the current value of the property to which the exemption pertains, the value on which the commercial facilities tax is based, and a current estimate of the number of jobs retained or created by the exemption.
History: 1978, Act 255, Imd. Eff. June 21, 1978
