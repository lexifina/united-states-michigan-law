# MCL 333.1117 References to repealed or rescinded provisions.
Sec. 1117. If a provision of a statute referred to in this code or in a rule authorized or recognized by this code is repealed, or if a provision of a rule authorized or recognized by this code is rescinded, and the provision is substantially reenacted or repromulgated, a reference in this code or the rule to the repealed or rescinded provision is considered a reference to the reenacted or repromulgated provision.
History: 1978, Act 368, Eff. Sept. 30, 1978
