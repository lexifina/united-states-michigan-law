# MCL 333.1113 Headings or titles of code.
Sec. 1113. A heading or title of an article or part of this code shall not be considered as a part of this code or be used to construe the code more broadly or narrowly than the text of the code sections would indicate, but shall be considered as inserted for convenience to users of this code.
History: 1978, Act 368, Eff. Sept. 30, 1978
