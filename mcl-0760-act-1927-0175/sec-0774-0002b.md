# MCL 774.2b File for criminal case; contents.
Sec. 2b. Each municipal court shall have a file for each criminal case. The file shall be in a suitable envelope, jacket, or folder, and shall contain the complaint, the warrant if returned, and any other papers filed in the case.
History: Add. 1957, Act 274, Eff. Sept. 27, 1957; Am. 1980, Act 506, Imd. Eff. Jan. 22, 1981
