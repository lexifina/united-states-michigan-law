# MCL 722.113m.added Installation of temporary door locking device or system.
Sec. 3m. (1) A temporary door locking device or system may be installed in a child care center in accordance with section 4i of the Stille-DeRossett-Hale single state construction code act, 1972 PA 230, MCL 125.1504i.
(2) As used in this section, "temporary door locking device or system" means that term as defined in section 4i of the Stille-DeRossett-Hale single state construction code act, 1972 PA 230, MCL 125.1504i.
History: Add. 2025, Act 62, Eff. Mar. 24, 2026
