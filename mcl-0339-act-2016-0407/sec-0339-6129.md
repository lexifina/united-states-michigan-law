# MCL 339.6129 Provision in conflict with Stille-DeRossett-Hale single state construction code act.
Sec. 1129. Any provision of this article that is inconsistent or in conflict with the Stille-DeRossett-Hale single state construction code act is superseded by that act to the extent of the inconsistency.
History: 2016, Act 407, Eff. Apr. 4, 2017
